03 How We Work

From plan to published site.

1

Plan

A Jira board with epics, user stories and tasks, run in two sprints.

2

Design

Page mockups and layouts in Canva, plus mobile layouts.

3

Build

Hand-coded HTML5 and CSS3, with every member coding at least one page.

4

Test & Publish

Validation, responsive and accessibility checks, then GitHub Pages.
