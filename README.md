# COS10026 Assignment 1 – VinFast Careers Website

## Project Overview

This project is a group assignment for **COS10026 – Computing Technology Inquiry Project / Web Technology**. The team is developing a responsive careers website inspired by VinFast.

The website introduces career opportunities, presents job information, allows candidates to submit applications, and provides information about the project team. The design aims to deliver a consistent visual experience across desktop and mobile devices.

## Team Members and Responsibilities

| Team Member | Assigned Page | Main Responsibilities |
|---|---|---|
| Nguyễn Nhật Thanh | Home (`index.html`) | Develop the homepage, introduce the careers website, create the main navigation and provide links to other pages. |
| Dương Nguyên Khôi | Jobs (`job.html`) | Present career opportunities, job descriptions, responsibilities, requirements and relevant employment information. |
| Đỗ Vũ Khánh Quỳnh | Apply (`apply.html`) | Develop the application form, implement form validation and organise candidate information fields. |
| Trần Quang Đại | About (`about.html`) | Develop the About page, introduce the team and present project-related information. |

All team members should coordinate to maintain consistent styling, navigation, accessibility and responsive behaviour across the website.

## Website Pages

### 1. Home Page – `index.html`
- Introduces the VinFast careers website.
- Presents the main visual banner and career-related content.
- Provides navigation to the Jobs, Apply and About pages.
- Guides visitors towards available job opportunities.

### 2. Jobs Page – `job.html`
- Presents available job opportunities.
- Displays job titles, reference numbers, employment information and descriptions.
- Includes responsibilities, essential requirements and relevant candidate information.
- Provides a clear pathway for candidates to proceed to the application page.

### 3. Apply Page – `apply.html`
- Provides an application form for candidates.
- Collects personal details, contact information, skills and experience.
- Includes supporting document upload interface elements where required by the assignment.
- Uses appropriate HTML form controls and validation.
- Provides a clear submission action.

### 4. About Page – `about.html`
- Introduces the project team.
- Presents relevant team or project information.
- Uses a layout consistent with the rest of the website.

## Technologies Used

- **HTML5** – Website structure, semantic elements and application forms.
- **CSS3** – Layout, typography, colours, reusable styling and responsive design.
- **Git and GitHub** – Version control, collaboration and source code management.
- **GitHub Pages** – Hosting and presenting the website online.

## Design and Development Goals

The team aims to:

- Maintain a consistent visual design across all four pages.
- Support desktop and mobile screen sizes using responsive layouts.
- Use semantic HTML and accessible form labels.
- Provide clear navigation and a user-friendly candidate journey.
- Keep the website structure organised and maintainable.
- Test links, form controls, page layouts and visual consistency before submission.

## Candidate Journey

The intended candidate journey is:

**Home → Jobs → Apply**

Candidates can explore the About page whenever they want to learn more about the team or project.

## Running the Website Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser, or use a local development server.
4. Navigate through the website using the shared navigation menu.
5. Test the layout at both desktop and mobile screen sizes.
