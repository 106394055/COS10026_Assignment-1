3. How We Work

From plan to published site.

1

Plan

A Jira board with epics, user stories and tasks, run in two sprints.

2

Design

Page mockups and layouts in Canva, plus mobile layouts.

3

Build

Hand-coded HTML5 and CSS3, with every member coding at least one page.

4

Test & Publish

Validation, responsive and accessibility checks, then GitHub Pages.

Tools We Use

Everything our team uses to plan, design, build and publish.

1. Jira

Plan sprints, track tasks and assign owners.

2. GitHub

Version control and GitHub Pages hosting.

3. Canva

Page mockups and layouts.

4. HTML5 & CSS3

Semantic, accessible page structure. Responsive, consistent styling.
